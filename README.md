# CbetaZenTexts

The complete CBETA XML corpus - ~5,000 unmodified Chinese texts in TEI XML format. Built for the [Read Zen](https://github.com/Fabulu/ReadZen) desktop + web environment.

## What's in here

```
xml-p5/          Complete CBETA XML TEI P5 files (Jan 2026 snapshot)
LICENSE          CBETA non-commercial license notice
NOTICE           Attribution notice
```

Files in `xml-p5/` are redistributed unchanged from [cbeta-org/xml-p5](https://github.com/cbeta-org/xml-p5). This is the full corpus, not a subset.

## License

The original XML texts are provided by **CBETA - Chinese Buddhist Electronic Text Association**. CBETA permits redistribution only for non-commercial use, provided the full CBETA header remains intact in every file. See `LICENSE` and `NOTICE` for details.

For texts with commercial-use-compatible licensing, see [OpenZenTexts](https://github.com/Fabulu/OpenZenTexts).

## Contributing

Download [Read Zen](https://github.com/Fabulu/ReadZen), clone this repository using the built-in Git tab, open a text, translate or improve a section, save, commit, and submit a pull request - all from within the app.

Machine translation is welcome as a first-pass baseline. Quality improves iteratively over time.

**Translator annotation:** At the top of each translated file, add a short annotation so contributions can be tracked:

```
resp: your-name
annotation: Machine translation using ChatGPT 5.2
```
